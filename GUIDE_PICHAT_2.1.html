1. Installer ou réparer

Place le dossier PiChat directement dans Téléchargements, puis colle :

cd ~/Downloads/PiChat
python3 pichat.py install

Si une ancienne installation a un problème :

cd ~/Downloads/PiChat
python3 pichat.py repair --rebuild

2. Lancer sur Mac et téléphone

cd ~/Downloads/PiChat
python3 pichat.py network

Le Terminal affiche une adresse du type http://192.168.1.20:8000. Ouvre-la sur les appareils du même Wi-Fi.

Sur iPhone, les notifications PWA complètes demandent en pratique une origine HTTPS. Le chat local reste utilisable avec l’adresse IP.

5. Mettre à jour sans changer l’application

Utilise le gestionnaire de mise à jour : il fait un backup, remplace le code, conserve la base et répare les dépendances.

cd ~/Downloads/PiChat
python3 pichat.py update ~/Downloads/NOUVELLE_VERSION.zip

L’icône PWA déjà installée reste la même. Le service worker active ensuite les nouveaux fichiers.

6. Préparer une URL publique

cd ~/Downloads/PiChat
python3 pichat.py prepare-internet https://chat.mondomaine.fr

Tu trouveras également la page /admin#deployment.

Un domaine, HTTPS, Caddy et un accès réseau/hébergement restent nécessaires. PiChat ne peut pas ouvrir automatiquement ton routeur ni acheter le domaine.
