PICHAT 3.5 PERFORMANCE — PATCH RAPIDE

Ce patch contient uniquement les fichiers ajoutés/modifiés depuis le dépôt 3.4 transmis.

MÉTHODE :
1. GitHub Desktop > Repository > Show in Finder.
2. Copie TOUT le contenu de ce dossier PATCH dans le dossier du dépôt.
3. Choisis Remplacer.
4. SUPPRIME aussi de ton dépôt s'ils sont encore suivis :
   - database/pichat.db
   - backups/PiChat_backup_*.zip
   - .DS_Store
5. Vérifie que venv/.venv et .env ne sont pas envoyés.
6. Commit : PiChat 3.5 PERFORMANCE
7. Push origin.
8. Render redéploie automatiquement. NE recrée PAS la base PostgreSQL.

Pour une mise à niveau la plus propre, le ZIP complet PiChat_v3.5_PERFORMANCE.zip est préférable.
