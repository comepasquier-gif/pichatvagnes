PICHAT 2.2.0 — MISE À JOUR PACKS FINAUX SUR MAC

1. Arrêter PiChat dans le Terminal avec Ctrl + C.

2. Créer un backup :
   cd ~/Downloads/PiChat
   python3 pichat.py backup

3. Décompresser la mise à jour depuis Téléchargements :
   cd ~/Downloads
   unzip -o PiChat_v2.2.0_Mac_Packs_Finaux.zip

4. Réparer et migrer la base :
   cd ~/Downloads/PiChat
   python3 pichat.py repair

5. Relancer sur le Mac et le Wi-Fi :
   python3 pichat.py network

6. Recharger complètement le navigateur :
   Mac : Cmd + Maj + R
   Application mobile : fermer complètement PiChat puis la rouvrir.

OUVRIR LES PACKS
- Utilisateur : PiChat > Social & planning
- Administration : http://localhost:8000/admin#final-packs

COMMANDES UTILES
- État des packs : python3 pichat.py packs status
- Backup immédiat : python3 pichat.py packs backup

IMPORTANT
Un message programmé ne peut partir que lorsque le Mac et le serveur PiChat sont allumés.
La mise à jour ne doit contenir ni pichat.db, ni .env, ni venv.
