1. Installation ou réparation

Place le dossier PiChat directement dans Téléchargements, puis colle :

cd ~/Downloads/PiChat
python3 pichat.py install

2. Lancer sur le Mac

cd ~/Downloads/PiChat
python3 pichat.py start

Ouvre http://localhost:8000

3. Lancer pour les téléphones

cd ~/Downloads/PiChat
python3 pichat.py network

L’adresse Wi-Fi à ouvrir sur les téléphones est affichée dans le Terminal.

4. Espaces et établissements

Après le lancement, ouvre http://localhost:8000/spaces. PiChat Central contient automatiquement les anciens comptes, salons et messages.

🏫 Plusieurs établissementsUne seule installation peut contenir plusieurs communautés isolées.
🔑 InvitationsChaque espace possède son code d’invitation.
# Salons par espaceCrée plusieurs salons et catégories dans chaque établissement.
🛡 Rôles locauxPropriétaire, admin, modérateur et membre par espace.

Commandes utiles

cd ~/Downloads/PiChat
python3 pichat.py admin toto totototo
python3 pichat.py user eleve 5C motdepasse
python3 pichat.py backup
python3 pichat.py doctor

Migration

La base existante est migrée automatiquement. La version 2.1.4 ne contient aucun fichier pichat.db, donc elle n’écrase pas tes données lors d’une mise à jour par-dessus l’ancien dossier.
