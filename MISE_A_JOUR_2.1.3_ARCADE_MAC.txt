MISE À JOUR PICHAT 2.1.3 — ARCADE & PACK DÉFIS

1. Arrêter PiChat avec Ctrl + C.

2. Sauvegarder les données :
   cd ~/Downloads/PiChat
   python3 pichat.py backup

3. Décompresser la mise à jour dans Téléchargements :
   cd ~/Downloads
   unzip -o PiChat_v2.1.3_Mac_Arcade_Pack_Defis.zip

4. Appliquer la migration et réparer les dépendances :
   cd ~/Downloads/PiChat
   python3 pichat.py repair

5. Relancer sur le réseau local :
   python3 pichat.py network

ACCÈS
- Arcade utilisateur : bouton Mini-jeux dans le chat.
- Administration : /admin puis Arcade.
- Commandes console : arcade, arcade on, arcade off, arcade-rewards on, arcade-rewards off.

La mise à jour ne contient pas de base pichat.db et ne remplace pas les comptes, messages ou PyCoins existants.
